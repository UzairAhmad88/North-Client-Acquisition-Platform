# Multi-Cloud Abstraction Layer
Decouples application business logic from specific cloud provider APIs. Supported drivers:
- **AWS**: VPCs, EC2, EKS, RDS, S3, CloudFront, Route53
- **GCP**: VPCs, GCE, GKE, Cloud SQL, Cloud Storage, Cloud DNS
- **Azure**: VNets, Azure VMs, AKS, Azure SQL, Blob Storage
- **On-Premise / Edge**: Bare metal, K3s/RKE2, Ceph, MinIO
