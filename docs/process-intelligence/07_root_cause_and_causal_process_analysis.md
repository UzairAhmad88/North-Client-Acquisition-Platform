# Root Cause and Causal Process Analysis

## Integration with Phase 75 Causal Intelligence
Correlation alone does not imply causation. The engine separates:
- **Observed Correlations**: Statistical co-occurrence of delay and trace attributes.
- **Causal Evidence**: Do-calculus interventions, counterfactual tests, and structural causal models (SCM).
- **Hypotheses**: Emerging patterns requiring deeper event sampling.
- **Confidence Metrics**: Bayesian posterior confidence scores for each candidate root cause.\n
