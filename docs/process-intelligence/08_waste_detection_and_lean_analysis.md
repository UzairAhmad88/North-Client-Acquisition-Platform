# Waste Detection and Lean Process Analysis

## 8 Types of Enterprise Waste (Muda)
1. **Waiting**: Delays between task completion and subsequent handoff.
2. **Rework**: Repeating failed activities or fixing data entry errors.
3. **Duplicate Entry**: Re-keying identical data across siloed systems.
4. **Unnecessary Approval**: Redundant sign-offs on low-risk transactions.
5. **Manual Transfer**: Swapping spreadsheets or manual copy-pasting.
6. **Excessive Handoffs**: Over-fragmented responsibility across departments.
7. **Over-Processing**: Performing unnecessary validation steps.
8. **Defects / Error Correction**: Rectifying operational failures.

## Lean Classification
- **Value-Adding (VA)**: Contributes directly to customer satisfaction or regulatory requirement.
- **Business-Necessary Non-Value-Adding (BN-NVA)**: Essential for internal operations/governance but invisible to customer.
- **Non-Value-Adding / Waste (NVA)**: Eliminable without functional penalty.\n
