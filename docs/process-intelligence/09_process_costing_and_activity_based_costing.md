# Process Costing and Activity-Based Costing (ABC)

## Multi-Dimensional Cost Model
Allocates total operational cost across:
- **Labor Cost**: FTE loaded hourly cost * active processing duration.
- **System / AI Compute Cost**: API token usage, GPU hours, license fees.
- **Infrastructure Overhead**: Fixed facility, tooling, and network allocations.
- **Defect & Rework Cost**: Remediation expenses, penalties, scrap.
- **Opportunity Cost**: Lost revenue resulting from customer churn or SLA breaches.\n
