# Enterprise Core Process Templates

The platform ships with pre-configured reference architectures for:
1. **Order-to-Cash (O2C)**: Order Capture -> Credit Check -> Fulfillment -> Invoicing -> Payment Settlement -> Reconciliation.
2. **Procure-to-Pay (P2P)**: Requisition -> Approval -> PO Issuance -> Goods Receipt -> 3-Way Match -> Payment.
3. **Record-to-Report (R2R)**: Journal Entry -> Intercompany Elimination -> Reconciliation -> Financial Close -> Regulatory Filing.
4. **Hire-to-Retire (H2R)**: Sourcing -> Offer -> Onboarding -> Career Development -> Compensation -> Offboarding.
5. **Incident-to-Resolution (ITR)**: Alert Detection -> Triage -> Containment -> Root Cause -> Remediation -> Postmortem.
6. **Contract Lifecycle Management (CLM)**: Drafting -> Redlining -> Approval -> E-Signature -> Execution -> Renewal.
7. **Project Delivery (PDP)**: Initiation -> Planning -> Sprint Execution -> Quality Assurance -> UAT -> Release.\n
