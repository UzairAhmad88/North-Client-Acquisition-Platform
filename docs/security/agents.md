# 16 Autonomous Security AI Agents

## 1. Agent Directory (`agents/security/`)
1. `monitoring_agent.py`: Continuous event ingestion and anomaly detection.
2. `detection_agent.py`: Multi-stage SIEM correlation and pattern matching.
3. `triage_agent.py`: Alert deduplication, risk scoring, and alert grouping.
4. `threat_intelligence_agent.py`: STIX/TAXII threat feed correlation.
5. `vulnerability_agent.py`: CVE prioritization and exploit analysis.
6. `identity_security_agent.py`: Continuous trust evaluation and JIT PAM.
7. `cloud_security_agent.py`: CSPM misconfiguration and drift scanning.
8. `application_security_agent.py`: SAST/DAST gating and DevSecOps compliance.
9. `data_security_agent.py`: Phase 65 data catalog exfiltration monitoring.
10. `ai_security_agent.py`: LLM prompt guardrails and tool boundary enforcement.
11. `investigation_agent.py`: Incident evidence gathering and hypothesis formulation.
12. `incident_response_agent.py`: SOAR containment execution.
13. `compliance_agent.py`: Automated framework control mapping.
14. `risk_agent.py`: Bayesian entity and organizational risk scoring.
15. `remediation_agent.py`: Patch and configuration fix recommendation.
16. `security_documentation_agent.py`: Automated compliance packet and postmortem generator.
