# Application Security & DevSecOps

## 1. CI/CD Security Pipeline
$$\text{CODE} \rightarrow \text{SAST} \rightarrow \text{DEPENDENCY SCAN} \rightarrow \text{CONTAINER SCAN} \rightarrow \text{SECURITY REVIEW} \rightarrow \text{DEPLOY} \rightarrow \text{DAST} \rightarrow \text{RASP}$$
Enforces automated deployment blocking if critical vulnerabilities exceed policy thresholds.
