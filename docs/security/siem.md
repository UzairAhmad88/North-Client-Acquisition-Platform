# Security Information & Event Management (SIEM)

## 1. Telemetry Pipeline
$$\text{SOURCES} \rightarrow \text{COLLECTION} \rightarrow \text{NORMALIZATION} \rightarrow \text{ENRICHMENT} \rightarrow \text{CORRELATION} \rightarrow \text{DETECTION} \rightarrow \text{ALERT}$$

## 2. Ingestion Sources
Aggregates application logs, authentication streams, API gateways, database query logs, cloud audit trails (CloudTrail), and AI agent tool invocations.
